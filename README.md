# Movira

Android-застосунок для вивчення мов. Перша мова — англійська, пояснення українською.

## Стан

Перша версія коду. **Ще не збиралася і не запускалася**: збірка й тести виконуються в GitHub Actions після першого запису в репозиторій.

Що вже написано:

- Перший розділ рівня A0 «Перші слова»: 6 уроків, 42 слова, 60 вправ. План із 12 розділів.
- Уроки відкриваються по черзі: наступний — після попереднього.
- Шість типів вправ: вибір варіанта, аудіювання, пропуск, пари слів, складання речення, переклад.
- Пояснення кожної помилки українською.
- Словник і повторення слів за алгоритмом SM-2.
- Серія днів і час навчання; прогрес зберігається на пристрої й працює без інтернету.

Чого ще немає:

- Облікових записів і синхронізації між пристроями.
- Розмови з AI-репетитором (потрібен сервер).
- Знайомства з тестом рівня, темної теми, оплат.
- Решти 66 уроків. Чернетки двох уроків для пізніших розділів лежать у `content_drafts/`.

## Як це влаштовано

| Папка | Що в ній |
| --- | --- |
| `assets/content/en/` | Курс англійської: `course.json` і уроки в `lessons/` |
| `lib/domain/` | Логіка без інтерфейсу: моделі, перевірка відповідей, повторення слів |
| `lib/data/` | Читання уроків і збереження прогресу |
| `lib/state/` | Стан застосунку (Riverpod) |
| `lib/features/` | Екрани: головна, шлях, урок, словник, профіль |
| `test/` | Автоматичні тести логіки й уроків |
| `tools/validate_content.py` | Перевірка файлів уроків на помилки |

Нова мова додається як нова папка в `assets/content/` без змін у коді.

## Перевірка

```
python3 tools/validate_content.py
flutter pub get
flutter analyze
flutter test
flutter build apk --debug
```

Ті самі кроки виконує `.github/workflows/ci.yml` при кожній зміні. Папку `android/` створює сам Flutter під час збірки, доки її не додано в репозиторій.

## Додати урок

1. Створіть файл `assets/content/en/lessons/<id>.json` за зразком наявних.
2. Додайте його `id` до потрібного розділу в `course.json`.
3. Запустіть `python3 tools/validate_content.py`.

Кожен урок перед випуском має перевірити людина, яка добре знає англійську.
